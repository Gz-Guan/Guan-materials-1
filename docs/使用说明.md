# Guan-Materials-1 使用说明

## 1. 用途

Guan-Materials-1 用于材料领域的文献检索、直接解读、候选创新审查、长期证据归档和导师汇报准备。它不限定金属焊接，可用于高分子、复合材料、陶瓷、涂层、能源材料和其他材料方向。

默认模式是“助手主导解读”：用户提供 PDF 后，助手直接整理引言逻辑、实验路线、特殊设计、结果、局限和候选研究问题，不要求用户先逐段阅读或回答问题。

## 2. 三种入口

### 只有研究方向

用户仅提供研究题目或大致方向时，Skill 必须先完成“资源预检”，不会立即搜索或推荐开题方向。它会一次确认：研究用途、学校图书馆/数据库入口、浏览器是否已登录，以及本地是否已有 PDF、参考文献表、Zotero/EndNote 文库或项目文件夹。只有这些状态已记录后才开始检索。

本地已有文献时优先整理本地文献；存在学校授权与登录状态时优先使用学校数据库；两者都无法使用时，Skill 会明确说明只能使用公开元数据，并在获得用户明确同意后才继续。预检未完成时，输出状态只能是“尚未开始”，不能形成候选文献、创新判断或开题结论。

### 已有题目、DOI 或参考文献表

Skill 跳过无意义的主题检索，先核对题名、作者、年份、期刊和 DOI，再按直接证据、近邻证据、类比证据分类。只有缺少全文或元数据时才补检索。

### 已有 PDF

Skill 直接进入论文解读，不再询问是否需要检索或下载。

## 3. 下载规则

如果当前环境具备浏览器控制能力、用户已在浏览器登录学校图书馆且授权下载，Skill 通过合法开放获取或学校授权路径下载全文。若不具备浏览器控制能力，则返回 DOI、出版社页和学校数据库检索路径，由用户自行下载。

Skill 不索要账号、密码、验证码、Cookie 或会话文件。没有项目文件夹时，才询问 PDF 保存位置。

## 4. 通用检索方法

Skill 不把“钛”“焊接”等词写死，而是先把题目拆成四类概念：

| 类别 | 含义 |
|---|---|
| 研究对象 | 材料、分子体系、复合材料、结构或试样形式 |
| 动作/现象 | 连接、制备、改性、降解、输运、相变或建模 |
| 目标响应 | 强度、黏附、导热、阻隔、稳定性、生物相容性等 |
| 边界 | 厚度、温度、环境、应用、设备和尺度 |

先以“对象 AND 动作/现象”宽搜，再加入目标响应和关键边界缩小结果。Skill 自动扩展同义词、缩写和常用拼写。

检索分两轮：

1. 第一轮召回约 20-30 篇候选文献。
2. 助手检查题目、摘要、DOI、材料体系和真实方法，剔除不满足核心概念的结果。
3. 若发现反复出现的无关主题，才为本课题临时生成排除词并进行第二轮精搜。

排除词只对当前课题生效。例如钛连接课题可排除 TiO2 光催化；高分子加工课题可能排除药物递送。不得把某一课题的排除词复用于其他材料方向。

## 5. 每篇论文的输出

每篇全文论文默认输出：

1. 文献角色与证据类型。
2. 引言逻辑：困难、空白和研究目标。
3. 实际贡献或创新点。
4. 完整实验/模型路线。
5. 特殊实验设计。
6. 按小节总结的结果与讨论，包含条件、观察、定量结果和原文锚点。
7. 一句话结论。
8. 局限、不可外推之处和缺失测试。
9. 可用于开题或论文的一条主张。

机制结论会标记为“直接实测”“模型预测”“作者解释”或“读者假设”。没有全文时，只能标为“摘要级线索”。

## 6. 候选创新审查

每篇论文结束后，Skill 先识别其实际局限，再围绕用户课题做范围受控的检索。结论只能写成：

- 已有人做过；
- 部分做过；
- 本次审查暂未检到。

最后一种不是创新点，只是待进一步验证的候选问题。每累计 5-10 篇，再合并重复问题进行一次跨论文审查。检索词、数据库、日期范围、排除词和结论都应保留。

## 7. 图片与归档

只保留能解释接头/样品装配、工艺流程、关键组织或关键趋势的图片，每篇最多三张。每张图必须记录图号、页码、用途和来源路径。

长期归档分为三层：

| 层级 | 内容 |
|---|---|
| 总索引 | 编号、题目、DOI、主题、状态、所属分卷和卡片路径 |
| 证据分卷 | 每 50 篇一份 Excel，保存完整证据卡、阅读日志和图片引用 |
| 文献卡片 | 每篇一份 Markdown，保存原文页码、图号和详细结论 |

单篇论文读完后只加入当天待归档列表；用户明确说“今天结束”后，再批量更新 Excel。

## 8. 导师汇报

用户提出“下周汇报”或“给老师汇报”时，Skill 输出：已确认事实、核心矛盾、拟定实验路线、对照组、风险、候选创新审查状态、需要导师决定的问题和下一周计划。

## 9. 常见问题

### 检索结果混入无关论文

不要直接按引用量排序。先检查对象、方法和目标是否同时满足，再通过标题/摘要字段、动态排除词和第二轮检索收紧结果。

### 没有浏览器控制或学校权限

Skill 仍可生成 DOI、出版社页、学校数据库检索式和候选清单；用户下载 PDF 后即可进入完整解读。

### 公开数据库结果质量差

公开元数据用于发现和 DOI 核对；涉及创新判断时，应补查学校购买的 Web of Science、Scopus、知网或万方等数据库，并明确记录尚未覆盖的来源。
